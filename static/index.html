      Acerca de Teti App

      Teti App es una aplicación de código abierto, disponible en GitHub y de libre distribución. Nació para hacer un aporte a la sociedad: podés descargar el código, personalizarlo y adaptarlo a tus necesidades.

      No tiene fines de lucro, pero si querés colaborar con una donación, el alias del equipo de desarrollo es:
